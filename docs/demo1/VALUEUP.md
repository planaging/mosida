# 모시다 데모1 — 벨류업판

원본(`Downloads\mosida-demo1\mosida-demo1`)은 그대로 두고, 이 폴더에 기능을 더한 버전을 따로 저장했다.
빌드 방법은 README.md "오늘 밤 순서"와 같다. 이 폴더의 `app/src/main/java/ai/planaging/mosida/` 아래를 통째로 복사하면 된다.
(새 폴더 `voice/` 가 하나 늘었다. AndroidManifest는 `<queries>` 블록이 추가됐다.)

> 컴파일은 아직 못 돌려본 상태다. 막히면 원본 폴더로 바로 돌아가 시연할 수 있다.

## 추가한 것 (8가지)

| # | 기능 | 왜 | 파일 |
|---|---|---|---|
| 1 | **음성 안내** — 다음 하차("다음 하차, 1번 어르신. 가람동, 2열 오른쪽 좌석입니다"), 벨트 풀림, 주행 중 문 열림, 잔류 감지, 전원 하차 시 "뒷좌석 확인" | 기사가 화면을 안 봐도 됨. 시연 임팩트 큼 | `voice/Announcer.kt`, `MainActivity.kt` |
| 2 | **주행 중 뒷문 열림 경고** — 빨간 큰 띠 + 음성 + 기록("경고") | 실제 사고 유형. 기존엔 주행 중 문 열림을 그냥 무시했음 | `TripController.kt`, `Screens.kt` |
| 3 | **결석 처리** — 출발 전 명단 각 줄의 "결석" 버튼. 좌석·인원·자동 배치에서 빠지고 기록에 "결석"으로 남음 | README 2단계 항목. 매일 생기는 일 | 전체 |
| 4 | **탑승 기록** — 운행 시작 순간 어르신별 "탑승 · 좌석"이 기록에 남음 | 기록이 탑승→하차로 완결돼 운행일지가 됨 | `TripController.kt` |
| 5 | **방금 하차 취소** — 잘못 누른 하차를 되돌림. 원래 기록은 지우지 않고 "하차 취소" 줄을 덧붙임 | 현장 실수 대비 + 기록 위조 불가 | `TripController.kt`, `Screens.kt` |

| 7 | **운행 요약** — 기록 화면 위에 출발·종료·소요·하차 n/n·보호자 인계·결석·경고 칸. CSV 끝에도 요약 붙음 | 센터 보고·운행일지 바로 사용 | `TripController.kt`, `Screens.kt` |
| 8 | **시연 길안내가 구간마다 바뀜** — "주행 시작"을 누를 때마다 다음 안내(우회전/좌회전/직진). 화살표도 문구에 맞게 | 영상에서 고정 문구 반복이 안 보이게 | `FakeVehicleGateway.kt`, `Screens.kt` |

작은 것: 운행 화면 상단에 "뒷문 열림" 표시, 기록 표의 구분 색(탑승 초록 / 결석·취소 주황 / 경고 빨강), 다음 하차 "n / 전체"가 결석 제외 인원 기준.

## 시연 순서 (벨류업판)

0. 좌석 배치: **6번 신○아 님 "결석"** 누르기 → 헤더에 "결석 1명" → "하차 순서대로 자동 배치" → "배치 완료 · 운행 시작"
   - 🔊 "다음 하차, 1번 어르신 …"
1. "주행 시작" → 주행 화면 → **주행 중 "뒷문 열기"** → 🔴 "주행 중 뒷문 열림" 띠 + 🔊 → "뒷문 닫기" → "정차"
2. "뒷문 열기" → 확인 창 → 하차 확인 → 🔊 다음 안내 → (실수 시연) **"방금 하차 취소"** → 다시 하차 확인 → "뒷문 닫기"
3. "주행 시작"(안내 문구가 바뀜) → "벨트 풀기" → 빨간 띠 + 🔊 → "정차" → "벨트 체결"
4. 반복 하차 (보호자 필요 어르신은 체크)
5. 전원 하차 → 🔊 "뒷좌석을 한 번 더 확인해 주세요" → "착석 감지" → "운행 종료" → 잠금 + 🔊 → **"직접 확인함 · 사람 없음 · 운행 종료"** → 바로 기록 화면
6. 기록 화면: 요약 칸(결석 1, 경고·확인 2 …) + 탑승/결석/하차/취소/경고 줄 → "엑셀로 내보내기"

## 알아둘 점

- **음성이 안 나오면**: 에뮬레이터에 한국어 TTS 음성이 없는 경우다. 앱은 정상 동작하고 소리만 빠진다. 끄려면 `MainActivity.kt`의 `useVoice = false`.
- 주행 중 문이 열린 채 정차하면 확인 창이 자동으로 뜨지 않는다. 문을 닫았다 다시 열면 뜬다(일부러 이렇게 둠: 주행 중 열림은 하차가 아니라 경고).
- "방금 하차 취소"는 마지막 1건만 되돌린다.
- Pleos SDK 이름(TODO VERIFY)은 원본과 똑같이 손대지 않았다. 가짜 차량 모드여도 `PleosVehicleGateway.kt`가 함께 컴파일되므로 이름이 틀리면 빌드가 막힌다 → 급하면 그 파일과 MainActivity의 `PleosVehicleGateway` 줄을 빼고 빌드.
